Robotics · Generative models

Learning a task as a game

An implicit generative model learns the inner structure of a robot task from demonstrations alone. Two networks compete until neither can improve, a Nash equilibrium, and at that point the generator produces new, valid trajectories for the task.

01 · The idea

Describe the task, or learn to produce it

Programming a robot task by hand takes an expert, and a task with many sub-goals is hard to write down. Reinforcement learning struggles too: the space of action sequences grows exponentially with the number of steps. There is another way to learn from examples.

Explicit model

Write down the distribution

Define a probability for every possible trajectory, then fit it. Every assumption about the task has to be stated, and a complex task needs a complex formula.

Implicit model

Learn to sample from it

Never write the distribution down. Train a generator that turns random numbers into trajectories that look like the demonstrations. The task's structure is learned inside the network.

A Generative Adversarial Network (GAN) is an implicit model. It needs only recorded trajectories, with no reward, no labels and no task rules.

02 · The game

A student, a judge and a teacher

Teacher · dataset

Demonstrations

Recorded robot trajectories of the task. The teacher never changes.

Player 1 · generator G

Student

Turns random noise z into a trajectory and tries to make it pass as a demonstration.

Player 2 · discriminator D

Judge

Sees a trajectory and says how likely it is to be real. It learns from the student's mistakes.

One player's gain is the other's loss, a two-player zero-sum game:

minG maxD Ex ~ data[ log D(x) ] + Ez ~ p(z)[ log(1 − D(G(z))) ]

The game ends at a Nash equilibrium: the student's samples follow the same distribution as the demonstrations, and the judge can do no better than guess, D(x) = ½ everywhere.

03 · For a robot

What the student learns about the task

For a robot, each sample is a whole trajectory: 512 time steps of 7 joint angles plus the gripper, produced in one shot from a 100-number noise vector. After training, the noise space has become a map of the task. Different points give different valid ways of doing it, with a different stroke order, direction or length, and moving between points changes the motion smoothly. The results are in the paper linked below.

Finding the closest demonstration

An implicit model has no encoder, so it cannot say directly which noise vector produces a given trajectory. Two methods recover it: look up the nearest real trajectory with k-nearest neighbours, or search the noise space with an optimiser until the output matches a target. The second is covered in Searching without gradients.

04 · How it's built

Convolutional generator and judge

Both networks are 1D convolutional, so they pick up local motion patterns along the time axis. Switch between training, where both networks learn together, and generating new motions with the trained generator. Hover a block for details.

Trained on eight drawing tasks, each with 46,000 to 100,000 trajectories generated in ROS simulation. Read more in thesis chapter 5 (PDF).
