Robotics · Representation learning

Seeing tasks the way people do

People describe what they see by its factors: shape, size, position, orientation. A computer sees only pixels. A disentangled model learns those factors on its own, so a robot can be told what to change, one factor at a time.

    03 · Why robots

    Why this matters for robot tasks

    For a robot, the output is not an image but a motion: a trajectory of joint angles. If the model that generates motions has disentangled factors, those factors become controls a person can use.

    Direct control

    "Draw it 5 cm further left" is one knob. With pixels or an entangled code, it is a new search or new training data.

    New combinations

    A shape seen only in one size and place can be produced in any size and place, because the factors are learned separately.

    Fewer demonstrations

    The model learns each factor once instead of learning every combination, which matters when robot data is slow to collect.

    Easier to trust

    Each part of the code has a meaning that can be checked, which helps debug and certify robot behaviour.

    04 · How

    How a β-VAE learns the factors

    A variational autoencoder compresses each example into a short code and rebuilds it. The β-VAE adds weight β to the term that keeps the code simple and close to independent Gaussian noise:

    loss = reconstruction error + β · KL( q(z | x) ‖ N(0, I) )

    With β above 1, the cheapest way to rebuild the data is to put each independent factor in its own code. Too large a β costs accuracy, so β is a trade-off between clarity and precision.

    In my PhD work, I applied this to a robot dataset recorded on a SCARA arm, built around five known factors: x position, y position, orientation, scale and shape. The model saw only the trajectories, with no labels for the factors.

    Read the full study: Task Level Disentanglement Learning in Robotics Using βVAE, International Journal of Electrical and Computer Engineering Systems, 2022. The thesis covers it in chapter 5 (PDF).
