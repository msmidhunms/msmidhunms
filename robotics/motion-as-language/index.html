Robot motion as a language

A complete robot task reads like a sentence. Each pose is a word, and every word depends on others, some next to it and some far away. Transformers learn exactly these links through attention, so I used them to learn robot tasks.

01 · The idea

Words in a sentence, poses in a task

In a sentence, a word's meaning depends on other words. Some are right beside it. Others are far away: in "draw the door below it", the word it points back to something said earlier. Transformers handle this with attention: every word looks at every other word and decides how much each one matters.

A robot task works the same way. On a Franka Emika Panda, each pose is described by its 7 joint angles. That vector is the robot's word. A task is a long sequence of these poses, and they depend on each other. Neighbouring poses must flow smoothly, and distant ones must agree: a drawn square has to close where it started, and a roof has to meet the corners of the walls. When all of these links hold, the motion is in harmony.

03 · The model

A Transformer that compresses and rebuilds a task

The Transformer-VAE reads the whole pose sequence at once. Each pose is embedded and given a positional encoding, so the model knows its place in time. Encoder layers apply multi-head attention, so different heads can track different kinds of link. The result is squeezed into a short latent code z, a summary of the whole task. The decoder attends to z and rebuilds the pose sequence. Sampling a new z, with a task label, generates a new trajectory for that task.

The modified version improves two things. It gives attention a wider working space than the latent code, with projection layers in between. And it judges the output the way the robot experiences it: forward kinematics turns joint angles into the position and orientation of every link, so the training loss checks where the arm actually is, not just its joint numbers. 04 · Why it fits

Why attention suits robot tasks

Long-range links

A recurrent model passes information step by step and forgets over long tasks. Attention connects the last pose to the first directly.

Whole task at once

All poses are processed in parallel, so the model sees the full shape of the task, not just the next step.

Several kinds of link

Multiple heads can track smoothness, shape closure and stroke structure at the same time.

New tasks from a code

The latent space holds the meaning of the task, so new, valid motions come from sampling or moving through it.
