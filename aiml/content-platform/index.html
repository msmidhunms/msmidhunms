01 · Overview

The problem

Content teams usually jump between separate tools to research a topic, plan keywords, draft copy, make images, schedule posts and publish. This platform brings the whole workflow together, with LLMs doing the heavy lifting at each step and people reviewing and editing together.

My role: I lead the AI team (two engineers) building the platform's AI features.

04 · In-app assistant

An agent inside the editor

The newest piece is an AI assistant that works inside the document the user has open. Rather than producing text in a separate chat, it acts through the platform itself.

Context

Reads the open document

Uses the current draft as context for what the user is asking.

Tools

Calls the platform's tools

Uses the existing writing and image tools instead of duplicating them.

Action

Generates and edits

Writes new content and makes edits directly in the document.

Safety

Guardrails

An agent harness with defences against prompt injection and against generating malicious snippets.

Why guardrails matter here: the assistant reads content that may come from the web or other users, and that content can contain instructions aimed at the model. The harness has to keep those instructions from steering the agent's tool calls.
